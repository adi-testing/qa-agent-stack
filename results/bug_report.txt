Title: Integer Overflow Error during Number Addition

Summary:
The current code encounters an overflow error when a large negative number (-1 * (2 ** 31)) is added to another number (1). This occurs due to Python's limit on the range of representable integers.

Steps to Reproduce:
1. Import the necessary modules.
2. Define a function `add(a, b)` that adds two numbers.
3. In the test case, call `add(-1 * (2 ** 31), 1)`.
4. Assert that the result is as expected (-2 ** 31).

Expected Behavior:
The code should correctly add the input numbers and return the correct sum (-2 ** 31).

Actual Behavior:
An overflow error occurs, causing the returned value to be incorrect or unexpected.

Suggested Fixes:
1. Use a library such as `python-decimal` for handling decimal numbers with arbitrary precision. Replace the failed assertion with this line: `assert add(Decimal(-1 * (2 ** 31)), Decimal('1')) == Decimal(-2 ** 31)`.
2. Change the data type to a big integer representation like `sage`. This can handle larger numbers more effectively, but may require additional setup and might not be as straightforward as using `python-decimal`.
