1. Test Case Title: Verify Password Reset Functionality with Correct Email Address
   - Steps:
     a. Register a new user with a valid email address.
     b. Set a password for the newly registered user.
     c. Forget the password and navigate to the password reset page.
     d. Enter the registered email address in the provided field.
     e. Click on the "Reset Password" button.
     f. Check the email inbox for a password reset link.
     g. Click on the received password reset link.
     h. Enter a new password and confirm it, then click on "Save".
     i. Attempt to log in with the newly created password.
   - Expected Result: The user should be successfully logged in using the newly created password.

2. Test Case Title: Verify Password Reset Functionality with Incorrect Email Address
   - Steps:
     a. Register a new user with a valid email address and password.
     b. Forget the password and navigate to the password reset page.
     c. Enter an incorrect email address in the provided field.
     d. Click on the "Reset Password" button.
   - Expected Result: An error message should be displayed indicating that the email address is not associated with any account.

3. Test Case Title: Verify Password Reset Functionality for Inactive Accounts
   - Steps:
     a. Register a new user with a valid email address and password.
     b. Deactivate the user's account by an administrator.
     c. Forget the password and navigate to the password reset page.
     d. Enter the registered email address in the provided field.
     e. Click on the "Reset Password" button.
   - Expected Result: An error message should be displayed indicating that the account is deactivated or inactive, and the user needs to contact an administrator for assistance.
